## what is python ??
- High level , interpreted , OOP language 
- Features dynamic and highly readable syntax 

## why is python populor ??
- simple English lie syntax 
- massive library and framework ecosystem.
- Highly versatile (web data science )

## Is Python Compiled or or interpreted ?
Both , but primarily considered as interpreted .
- source code compile to internal bytecode (.pyc) 
- python virtual machine (PVM) interpret line by line .

## What are python basic datatypes ? 
 * Text : str
 * Numeric : int, float , complex
 * sequence : list , tuple, range 
 * Mapping : dict 
 * Set : set, frozenset
 * Boolean : bool
 
## Difference between / and //
 - / is Float division (returns decimal like 5/2 = 2.5 )
 - // is floor division (rounds down to integer like 5//2 = 2)

## Difference between = and ==
- = is assignment operator
- == is comparison operator


## what is indentation ? 
- Spaces or tabs at the beggining of a code line .
- pyton uses is to define code blocks instead of {}

## What is dynamic Typing ??
- Variable type are determine at runtime, not compile time .
- You do not need to declare variable types explicitly. (e.g. x = 5 )
